# NEURODOOM / Godot

This folder is the production track for NEURODOOM.

The browser implementation at repository root remains a reference implementation while systems are ported.

## Current vertical slice

Flow:

1. spawn in the A3 containment sector;
2. fight security units;
3. use the neural terminal;
4. restore power;
5. open the security door;
6. reach and interact with the SHIVA core;
7. complete the slice.

## Art direction

The target is intentionally stylized rather than photorealistic:

- painterly/gritty surfaces;
- simple readable silhouettes;
- dark industrial palette;
- cyan/magenta as controlled emissive accents;
- billboard enemy sprites;
- first-person weapon viewmodels;
- fog and localized lighting.

## Controls

WASD / mouse / LMB / E / Shift.

F5 quick-save, F9 quick-load.
